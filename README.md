# 🤖Chatbot
This project showcases a lightweight yet powerful conversational AI platform. By leveraging the native UI components of Streamlit (such as st.chat_input and st.chat_message), the app mirrors a modern chat room environment. The backend integrates with the Google Generative AI SDK, allowing users to seamlessly prompt advanced LLM models like Gemini 1.5 Flash or Gemini 2.0 Flash.

The system utilizes Streamlit's session_state to store and manage active conversation logs. This mechanism guarantees that the Gemini engine retains historical context throughout a multi-turn session, ensuring coherent and deeply contextual answers

## 📍Features
* **Live Chat Interface:** Clean, intuitive UI built entirely with Streamlit.
* **Google Gemini Integration:** Powered by the official `google-genai` SDK.
* **Context Preservation:** Chat history is maintained during the active session.
* **Streaming Responses:** Text generates dynamically in real-time for fluid conversations
